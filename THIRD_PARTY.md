# Third-party components

Windows target-curve resources in `windows/OpenEQ.Desktop/Assets/Targets/` are copied from Jaakko Pasanen's AutoEq project, commit `7ae0f56d53074872b028649617a22bbb4232feb7`, under its MIT license (Copyright 2018–2022 Jaakko Pasanen). The full notice is `Assets/Targets/LICENSE-AutoEq.txt` and must accompany distributions. `catalog.json` records each original file, source URL and SHA-256. These are AutoEq-provided datasets, not an assertion of endorsement or certification by Harman, GRAS, B&K or ISO. Original OpenDSP relative preference curves are labeled separately.

Windows builds use NAudio 2.2.1 by Mark Heath and contributors under the MIT license. The full notice is preserved in `third_party/NAudio-LICENSE.txt` and must accompany distributions. NAudio WASAPI / Core / WinMM / WinForms / ASIO / MIDI assemblies retain their original identity; OpenEQ does not claim authorship of these libraries.

NAudio's WdlResampler is a C# port of the Cockos WDL resampler by Mark Heath, used in NAudio with permission from Justin Frankel. Original WDL copyright: Copyright (C) 2005 and later Cockos Incorporated; portions copyright other contributors. Its source and notice are available at https://github.com/naudio/NAudio/blob/v2.2.1/NAudio.Core/Dsp/WdlResampler.cs . OpenDSP vendors an altered copy in `RealtimeWdlResampler.cs` retaining the full WDL notice: the buffer servo uses one prebuilt worst-case cutoff across its bounded +/-2000 ppm range and capacity-only input buffers to avoid coefficient rebuilds and allocations on the render thread. The 256-tap / 256-phase sinc algorithm remains unchanged. `ClockedResampler.cs` supplies the clock servo.

The optional Windows diagnostic Python script uses python-sounddevice / PortAudio and cffi from a project-local dependency directory. Those dependencies are not part of the native desktop distribution and must retain their respective notices if redistributed.

Self-contained Windows distributions include Microsoft .NET 8 Desktop Runtime under the Microsoft .NET Library license terms. The official `LICENSE.txt` and `ThirdPartyNotices.txt` from the installed runtime are shipped alongside the executable as `DOTNET-LICENSE.txt` and `DOTNET-ThirdPartyNotices.txt`.

## Local-only historical test tools (not dependencies, not distributed)

Virtual Audio Cable 4.70/4.71 Trial (Eugene V. Muzychenko, shareware, **not open source**) and the SaviAudio/Savitech BRAVO-HD ASIO driver package (vendor-proprietary) were installed on the development machine while testing the old loopback/relay chain. They are not linked, bundled or required by the current native APO / rootless USB paths. Their packages, installers and test-signed drivers are excluded by `.gitignore`; no binaries are uploaded to the repository or Releases. VAC's official distribution policy would permit unchanged, non-commercial redistribution of the trial ZIPs, and the local copies were verified byte-identical to the official downloads, but the project does not redistribute them because they are no longer used. See `docs/第三方组件与许可.md` for the full component list and official references.

Android arm64 native capability probing dynamically links unmodified libusb 1.0.30, pinned to upstream commit 87a55632db62c9bdc58cd31d3ccfa673f1bb017f. It is licensed LGPL-2.1-or-later, separately from OpenEQ's MIT code. Complete library source and its original notices/build instructions are in `third_party/libusb/`; the license is also included in APK assets `licenses/libusb-LGPL-2.1.txt`. `build-native.ps1` rebuilds the replaceable shared library. Users may modify, rebuild and replace that component and debug such modifications; OpenEQ imposes no restriction on those LGPL rights. USB capability probing is not yet a completed USB audio output implementation.

The decent-player and libsamplerate checkouts under ignored `build/research/` are research references, not linked or distributed components. No Felicity harness source is included.

The Windows native APO in `windows/OpenEQ.Apo/` is original OpenEQ MIT code using Microsoft Windows SDK COM/APO interfaces and the installed MSVC toolchain/runtime. It does not link Equalizer APO, reuse its DSP or include Microsoft SYSVAD sample source. The NAudio/WDL dependency remains in the optional loopback bridge; the native APO itself has no resampler dependency.
