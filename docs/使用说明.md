# OpenDSP 0.4.0 使用说明

一句话：这是一套跑在电脑和手机上的耳机 EQ 与 DSP 工具。电脑端不用装驱动、不用虚拟声卡；手机端不用 Root，插上 USB DAC 就能走完整 DSP。预设是一份 JSON，两端通用。

**当前状态：本地定版，尚未公开发布，未来会开源到 GitHub。** 安装包是开发签名，不是商店正式签名；配置文件与预设都在你自己机器上，不上传、不联网、没有账号。

---

## 一、Windows 版（OpenDSP.exe）

### 装与卸

- 解压 `OpenDSP-Windows-0.4.0-single.zip` 到任意文件夹，双击 `OpenDSP.exe`。自带 .NET 8 运行时，不用另装。
- `OpenEQ.Apo.dll`、`Assets` 文件夹、`LICENSE.txt` 必须和 exe 放在同一目录。
- 首次绑定物理输出设备会弹 Windows 管理员权限；APO 是未签名的开发组件，启用前软件会说明影响并备份原有音效设置。
- 不想用了，删掉整个文件夹即可，不写注册表。

### ⚠️ 重点：384 kHz 不是所有应用都吃得下

**有些应用，特别是游戏，在 384 kHz 的系统输出格式下不能正常工作。把它们切到 192 kHz 就好。**

会遇到的现象：游戏没声音、爆音、卡顿、启动报错找不到音频设备，或者音效时有时无。这不是 EQ 调坏了，是这些应用（或音频驱动）对超高采样率的共享格式兼容性不好。

**在软件里改（推荐）**

1. 打开「设备」页，找到 **采样率** 下拉框，选 `192000`（也可以直接输入 `192000` 再按回车，让程序去问驱动支不支持）。
2. 位深保持 `32-bit`（或驱动列出的可用值）。
3. 点 **「同步到系统」**。软件会先把原来的格式备份下来，再改物理端点与系统混音格式。
4. **重开那个游戏或应用**。播放器如果报设备失效，关掉重开就行。

注意这几点：

- 「USB 独占」开着的时候不能同步系统格式，先关掉独占；同步完再按需开回去。
- 有其他程序正在放声音时，软件会拒绝改格式，这是故意的保护。先把播放器停了。
- 切换格式会短暂断一下音；原有格式有备份，在「更多」菜单里可以恢复。
- 也可以走 Windows 自己的路子：设置 → 系统 → 声音 → 输出设备 → 设备属性 → 高级 → 默认格式，改成 `192000 Hz / 32-bit`，然后重开应用。软件内同步更稳，因为带备份。

**会不会掉音质？** 不会。你听的音乐绝大多数是 44.1 / 48 kHz，192 kHz 仍然是它的四倍；EQ 系数按实际处理采样率重新计算，滤波、声场、压缩一个不少。要用回 384 kHz，同样的步骤改回去即可。这条只是**兼容性开关**，不是性能档位。

### 其他常用提示

- 默认走自研原生 APO（Windows 共享音频路径），不装虚拟声卡、不复制一遍系统声音。ASIO / WASAPI 独占 / 绕过系统音效 / 受保护内容不保证接管。
- 想玩 USB 独占：关掉「原生系统 EQ」，选虚拟音频入口，再打开顶部 USB 独占。DSD DoP 直送请用 DAC 硬件音量。
- 首次安装/升级/卸载开发版 APO 会短暂重启系统音频，等播放器恢复再判断声音。
- 新建平直预设的软件增益是 0 dB；sample-peak 保护不是 true-peak 限幅器。

## 二、Android 版（OpenDSP-Android-0.4.0.apk）

- 适用 Android 9+ / arm64，目标 Android 16。开发签名 APK，直接安装即可，**不需要 Root，不改系统设置**。
- 覆盖安装会保留预设、音量与已授予的权限；降级前先导出预设。
- 首次运行会要通知、附近设备（蓝牙）、录音（播放捕获）权限，按实际用途手动允许。录音权限不给，播放捕获类功能就不可用，系统耳机 EQ 仍可用。
- **音量现在是 1% 一档**：20% 以下每档约 2 dB，20% 及以上和以前完全一样，100% 仍是原来的最大输出（精确 1.0），0% 静音。低阻高敏耳机请从 1–5% 开始往上找，别一下拉到 20%。硬键、通知栏按钮、媒体会话都是 1% 一档。
- USB 独占需要 OTG + DAC（幻音 4X 实测过）。界面显示的 384k 是**输出格式**，不代表音源是 384k。系统允许哪些应用被捕获由 Android 政策决定，不承诺接管全部应用。
- 预设：内置 21 份，可导入 PC 的 `OpenDSP-PC预设库.json`；装好 ADB reverse 后，在「同步」页可以做电脑 ↔ 手机双向同步，冲突保留双方、不自动覆盖。
- 系统耳机路径（蓝牙/有线）走系统 DynamicsProcessing，是幅频近似，不等于完整 32 段 PEQ；空间、延时、反相和自研压缩不在这条路径生效。

## 三、出问题先看这里

| 现象 | 先做这个 |
| --- | --- |
| 游戏没声 / 爆音 / 卡顿 / 报设备错误 | 采样率从 `384000` 改 `192000`，点「同步到系统」，重开应用 |
| 点「同步到系统」没反应 | 关掉「USB 独占」；停掉其他正在播放的程序；检查设备是否待重启 |
| 手机插上 DAC 没声音 | 确认 OTG、USB 授权弹窗已允许、DAC 被认领；检查是否停在 0% 音量 |
| 手机音量 1–2% 还是太响 | 这是低阻高敏耳机的硬件增益，往下降档位；DSD 直送时改用 DAC 硬件音量 |
| 后台跑一会儿断了 | 检查厂商省电策略 / Doze 白名单，别让系统杀前台服务 |
| 某个 App 没被 EQ 处理 | 播放捕获受系统与应用自身许可限制，不是所有应用都能接管 |
