# 第三方组件与许可

**随 OpenDSP 构建和运行分发的，全部是开源组件。** 本项目没有链接任何专有 DSP 库、没有捆绑闭源驱动，也没有把商业软件打进安装包。开发过程中在本机试过的虚拟声卡与厂商驱动属于历史测试残留，用不到了，既不进源码仓库也不上 Release。

## 随产物分发的组件

| 组件 | 用在哪 | 许可 | 分发方式 | 许可 / 源码位置 |
| --- | --- | --- | --- | --- |

| NAudio 2.2.1 | Windows 音频 IO（WASAPI / ASIO / WinMM 等） | MIT | .NET 程序集随桌面端发布 | `third_party/NAudio-LICENSE.txt` |
| Cockos WDL resampler（NAudio 的 C# 移植，作者授权） | 可选中转链路的重采样 | Cockos WDL 授权，保留完整声明 | 仅源码改写份随项目 | `RealtimeWdlResampler.cs` 内保留原始声明，`ClockedResampler.cs` 提供时钟伺服 |
| AutoEq 目标曲线数据 | 目标拟合参考曲线 | MIT | 数据文件随桌面端发布 | `Assets/Targets/LICENSE-AutoEq.txt`，`catalog.json` 记录来源与 SHA-256 |

LGPL 提示：libusb 是**可替换的动态库**，`build-native.ps1` 从 `third_party/libusb/` 源码重建，用户可以修改、重建、替换并调试该组件，LGPL 权利不受本项目限制。

## 本机历史测试残留（不是依赖，不分发）

开发早期跑「虚拟入口 → 回环 → USB 独占」中转链路时，本机装过这些工具；现在主链路是 Windows 自研原生 APO、Android 免 Root USB 独占，它们已经用不到了：

- **Virtual Audio Cable 4.70 / 4.71 Trial**（Eugene V. Muzychenko）：共享软件，**不是开源**。官方 [Distribution policy](https://vac.muzychenko.net/en/distrib.htm) 允许「原样、非商业」免费分发，本地副本与官网原包 SHA-256 一致；但因为用不到，我们不挂。
- **SaviAudio / Savitech BRAVO-HD ASIO 驱动包**（含微软 Windows Installer 3.1 再分发包）：厂商专有驱动，未查到第三方再分发授权，不挂。
- **Steam Streaming Speakers**：仅出现在 `tests/` 与诊断脚本里按设备名查找的旧测试代码，不安装、不捆绑。

源码里 `Program.cs`、`BluetoothTest.cs` 等按名称查找虚拟入口，属于旧中转链路的自检逻辑，不构成对上述任何软件的运行时依赖。`tools/vac/`、`tools/acmee-asio-install/`、所有安装包与测试签名驱动都在 `.gitignore` 里，只留在本地开发机。

如果你要复现旧中转链路，请自行从官方获取（与本项目无关联、无背书）：
VAC <https://vac.muzychenko.net/en/download.htm> ｜ BRAVO-HD 建议用你 DAC 厂商官网的对应驱动，参考 [Creek Audio 安装说明](https://creekaudio.com/usb-class-2-software-installation-guide/) / [Hifime 指南](https://hifimediy.com/savitech-asio-driver-installation-guide/)。

## 我们自己的代码

`core/`、`android/`、`windows/OpenEQ.Apo/`（原生 APO）、桌面端 DSP 均为本项目原创 MIT 代码。原生 APO 只用 Windows SDK 的 COM / APO 接口与 MSVC 工具链，没有复用 Equalizer APO、没有引入 SYSVAD 源码。签名私钥 `signing/debug.jks` 永不上传。

完整声明见根目录 `THIRD_PARTY.md`；项目许可见 `LICENSE`。
