# SGOR Luna / 幻音4X：细化试听包（2026-10-23）

按用户实听反馈调整：原声两端略多，低频下潜良好，高频偏多且尖。前级保持0dB。
主力方案使用13–14段中等Q滤波，分开控制中低频、人声、硬边、齿音与极高频。不是耳机单体实测校准。

| 编号 | 名称 | 这次的侧重 |
|---|---|---|
| 00 | 原声对照 | 不加滤波，保留0dB原声参考。 |
| 01 | 均衡流行 | 轻收中低频，保留主体厚度，分区抑制高频尖锐感。 |
| 02 | 甜润贴耳女声 | 细分人声厚度、实体感和靠前程度，压住齿音及高频硬边。 |
| 03 | 清亮日系 | 亮度主要来自人声咬字，不再额外抬高本来偏多的高频。 |
| 04 | 冷静清晰 | 更收中低频，保留清晰的中频轮廓；不是严格DF校正。 |
| 05 | 燃系V型 | 收敛原生V型的高频，保留少量鼓点冲击，不再大幅两端加量。 |
| 06 | 电子低频 | 少量强调深低频，中低频另行收束，高频保持柔和。 |
| 07 | OST开阔 | 保留原有微扩展，少收极高频，减少遮蔽而不堆高频。 |
| 08 | 柔顺耐听 | 更明显但平滑地抑制硬边和齿音，保留中频厚度。 |

00和单独的原声对照仍然完全平直。05/06仅保留少量风格性深低频提升，其他主力方案不抬深低频。
不要把这些滤波器继续叠加到旧EQ上：软件库中的同名方案已经替换。
保持原有宽度、压缩器、延时、输出增益和峰值保护设置；同前级不等于严格等响。
正增益仍可能触发已有峰值保护。先听当前女声档，再对照00；重点反馈齿音、暗闷感和人声厚度。
调节点用途：95Hz 中低频冲击量；180Hz 低频厚度；340Hz 低中频遮蔽；700Hz 人声厚度；1150Hz 人声实体感；1850Hz 女声靠前程度；2750Hz 咬字清晰度；3950Hz 上中频硬边；5250Hz 偏低的齿音/金属感；6650Hz 齿音主体；8350Hz 高频尖锐感；10200Hz 高频余量；12500Hz 极高频整体亮度。
8kHz附近及更高频受佩戴和耳套影响明显，此处采用适度宽带调整，不假定有已测出的精确共振峰。
