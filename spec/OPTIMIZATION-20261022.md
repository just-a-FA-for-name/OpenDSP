# OpenDSP rc19 优化记录

## DSD 数值检查与修复

现有路径是 PCM → DSP → DSD 调制 → DoP → 幻音 4X。
本次没有更换驱动、重启音频服务、重新绑定 APO，亦未自动播放测试纯音。

基线离线检查发现：

- 原设计扫描的是反馈传递函数 `NTF - 1`，却把它当作 NTF 峰值；
  扫描耗尽后也没有报告失败。原实际 NTF 峰值约 1.326，不能说它超过了 1.45。
- 0.9 满幅比例的调制输入可使内部状态升至约 1.12e8（DSD64）或 4.17e9（DSD128）。
- 一个 NaN 输入会污染历史，随后静音输入也持续生成全零位流；
  DoP 标记仍合法，原标记校验无法识别此问题。

rc19 改动：

- 用真实 NTF 校验设计目标；不接受无解的设计参数。
- PCM 进入 DSD 前采用 50% 调制参考电平（−6.02 dB 数字余量），保留有效信号的形状。
- 限制插值过冲，计数可由 AI 查询；拒绝非有限输入及异常失稳状态。
- 这项余量在封包前完成，未对 DoP 载体做音量运算。载体音量租约和恢复机制保留。
- PCM 分支没有增加上述 DSD 衰减。DAC 的 DSD 增益补偿各异，最终听感音量需实听。

资料：

- DoP 1.1： https://dsd-guide.com/sites/default/files/white-papers/DoP_openStandard_1v1.pdf
- DSD 电平与调制稳定性： https://help.roonlabs.com/portal/en/kb/articles/dsd-to-pcm-settings

**这些修复不能直接证明幻音 4X 每 20–30 秒短断已经消失。**
此前低电平独立播放器也有短断，因此仍需该设备的新版本实听与独立正常 DSD 基线。

## AI 调音与高级分析

- 完整预设的只读预览、一次应用、撤销。
- Revision 覆盖参数与输出上下文，拒绝过时方案。
- 余量估算考虑 EQ、矩阵/宽度、压缩器正补偿；旁路状态也按实际生效的增益位置处理。
- 四通路线性幅频、相位及群延迟分析，可通过 MCP 或设置页导出 JSON。
- 修复 MCP 参数覆盖命令、格式化 JSON 成功响应误判、坏请求影响服务的问题。
- 管理式 DSP/PCM 分支增加非有限采样防护，避免一个 NaN 污染滤波器/能量统计，
  或在整数转换时变成满幅负电平；`get_audio_diagnostics` 可读取计数与最近错误。
- 现有单段 EQ、压缩器、矩阵、DC 阻断、目标曲线及手动 GUI 保留。

接入说明见 [AI_TUNING.md](AI_TUNING.md)。

## 验证边界

离线用合成数据和隐藏预览窗口验证，不改真实预设、不生成设备试听音。
报告位于 `evidence/*20261022.json`。原源码备份位于
`build/dsd-review-20261022/original/`，基线数值报告为
`evidence/dsd-numerical-baseline-20261022.json`。

本轮尚未实现 native ASIO、FIR 卷积、真实 true-peak 限幅或耳机自动声学校准，
也不将这些功能写成已完成。
