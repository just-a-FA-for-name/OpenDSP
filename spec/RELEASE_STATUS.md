## 本轮已经落地的修复

- 物理 PCM 格式与 Windows 内部 float 混音格式分别读取和显示。
- 格式变更前先持久保存原始设备/混音格式；跨多次修改保留最初值。
- 核对位深、有效位数、通道、编码与采样率，切换失败尝试回退并保留无法确认的恢复记录。
- 恢复失败可重试；没有备份时拒绝用驱动默认值冒充原始设置；其他程序改过的格式不会被静默覆盖。
- 沿设备树检查待重启状态，阻止继续修改格式或安装音效。
- 18 项故障/共享文件读取检查通过；只读实机确认当前幻音 4X 是 48 kHz / 32-bit、无 OpenEQ APO，未签名音效加载已关闭。
- 播放中的设备禁止直接修改格式；安装后不再多做端点隐藏/显示。
- 安卓基础与 Root PEQ 真机复测通过，Root 路由在结束后注销；仍为 Android 共享输出，不是 USB 独占。

以上恢复代码尚未通过真实设备格式变更/故障恢复验收。
