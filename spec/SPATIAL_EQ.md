# OpenDSP rc23：高级EQ与声场

主界面主EQ下方新增“高级 EQ / 声场”。原有32段双声道/左/右EQ保留，
另有Mid和Side各16段独立EQ，支持峰值、低架、高架、低通、高通、陷波和全通。
新增模块默认关闭；升级不改变当前声音设置。

## 使用

1. 点“应用试听场景”，会启用选定场景；或者先编辑参数，再打开“启用空间处理”。
2. 展开高级参数，可调中央/侧向增益、低中高频宽度、分频点、
   交叉馈送量/低通频率/延时、整体效果混合和单声道混合。
3. “编辑中央 / 侧向 EQ”打开两组表格，各最多16段，支持添加、删除、清空与频响预览。
   保存后由空间总开关决定是否生效；取消不会改变实际参数。
4. “旁路”保留设置但停止空间处理；“恢复默认”关闭并重置空间模块；均支持撤销。
   输出级单独恢复保留空间设置，“全部输出处理恢复默认”包含空间模块。

| 场景 | 作用 |
|---|---|
| 自然交叉馈送 | 缓和硬左右分离，保持居中的单声道信息 |
| 宽阔伴奏 | 低频宽度65%，中频145%，高频165%，侧向高频轻收 |
| 中央女声 | 中央增益和存在感轻提，侧向略退；不是人声提取 |
| 低频收中 | 低频侧向渐减，中高频轻扩展 |
| 单声道对照 | 效果混合100%时输出两声道相同，便于对照 |

空间配置属于完整预设的一部分；切换其他预设时也会随预设切换。
五个场景仅替换空间模块，保留主EQ、前级、旧矩阵、输出增益和传输格式。
旧矩阵的全频宽度仍会叠加，已有宽度不为100%时需一起考虑。
效果混合0%为原输入，100%为完整处理；单声道混合同样受此比例控制。

## 处理与边界

处理顺序：主L/R EQ → M/S EQ与增益 → Side分区宽度 → 交叉馈送 → 效果混合 →
既有矩阵/全频宽度 → 增益、平衡、极性、延时 → 压缩与峰值保护。

M=(L+R)/2、S=(L−R)/2。Mid包含共同信息，Side包含差异信息，
不能据此断言Mid就是独立人声或Side就是独立伴奏。
分区宽度采用互补的一阶低通差分，全部100%时保持原比例；过渡平滑，
低频宽度0不是严格砖墙式的低频单声道。

交叉馈送对低通并延迟后的Side做衰减，等效于左右互送且抵消同声道的相同部分，
保持居中的单声道信息。参数最多45%、100–1500Hz、0–0.8ms。
这是耳机交叉馈送，不是个性化HRTF、房间卷积或保证耳外定位的虚拟扬声器。
声像宽度、集中感和空间听感依赖录音和佩戴，需要实听；更宽不必然更好。

主EQ图只显示主L/R EQ。高级编辑器显示各M/S滤波组；
设置导出的四路幅频、相位、群延迟，以及AI的`analyze_response`包含完整线性空间处理。
目标曲线拟合只针对主EQ；空间块开启时会提示拟合误差不代表最终耳机响应。
做声学基准匹配时可先旁路空间块，再微调偏好。

## 支持路径

本轮支持托管中转DSP，即用户当前USB独占384kHz/32-bit链路；
处理也位于该链路的DSD编码之前。现有Windows原生APO没有这些扩展字段，
启用空间模块的预设会被明确拒绝，不会静默忽略，也不为新功能重绑APO或重启音频服务。
DSD64/128在幻音4X上的连续试听仍是原有待验证项。

## AI / MCP 0.5

- `get_preset`读取`output.spatial`；修改副本，保留其他参数。
- `list_spatial_scenes`读取五个场景及完整配置。
- `set_spatial(spatial, expected_revision)`成组替换空间块；默认值补齐未提供字段，
  因此编辑已有配置时应先读取完整配置。
- `apply_spatial_scene(scene_id, expected_revision)`只应用空间场景。
- `reset_output(section:"spatial", expected_revision)`恢复空间默认值。
- 也可继续使用完整`preview_preset`/`apply_preset`/`undo_preset`。

MS滤波器采用原Band格式，所在数组决定M或S，`channel`固定为`both`。
余量估算计入M/S滤波、分区宽度、交叉馈送、混合和既有矩阵。
本用户前级保持0dB；正增益可能触发已有峰值保护，不能把自动余量计算当作声压测量。

## 验证

离线384kHz检查覆盖：默认与旁路、M/S隔离、中心单声道保持、单声道场景、
分区宽度方向、逐样本处理与复数传递函数的一致性、完整矩阵顺序、
余量估算、原生路径拒绝、保存回读、异常采样防护以及参数更新音频回调零分配。
同时检查32段主EQ加16段Mid/16段Side的满配置处理。
没有向耳机播放测试纯音；不凭这些数值宣称某场景一定更好听。
