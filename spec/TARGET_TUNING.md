# OpenDSP rc22：模块默认值与AI目标调音

## 恢复默认

主界面输出级、压缩器、声道矩阵分别提供恢复按钮；输出级下还有“全部输出处理恢复默认”。
每次恢复作为一个完整操作进入撤销历史。

| 范围 | 默认值 |
|---|---|
| 输出级 | 增益0dB、居中、左右延时0、正常极性、峰值保护开启/−1dBFS |
| 压缩器 | 关闭；阈值−18dB、比例4:1、启动10ms、释放120ms、拐点6dB、补偿0dB |
| 矩阵 | LL/RR=1、LR/RL=0、宽度1（100%） |
| 全部输出处理 | 以上全部恢复，直流滤波关闭 |

单模块操作保留其他模块。EQ频段、前级、设备、采样率、位深和DSD模式不属于这些恢复项。
AI使用`reset_output(section, expected_revision)`，版本过时会拒绝；可用`undo_preset`回退。

15条声学数据来自AutoEq，固定到commit
`7ae0f56d53074872b028649617a22bbb4232feb7`，保留原CSV、来源、SHA256与MIT声明：

- Harman IE 2016、2017-1、2017-2、2019、2019无低架；
- Harman OE 2013、2015、2018、2018无低架；
- 扩散场5128、5128 −1dB/oct、GRAS KEMAR、ISO11904-1；
- JM-1带Harman高频的基础数据、AutoEq IE基础数据。

基础数据按原CSV提供，不擅自加上AutoEq某些预设另外指定的低架。
这些不是品牌官方认证或背书。具体来源见`Assets/Targets/catalog.json`。
711、GRAS、GRAS-KEMAR、5128和ISO11904-1分别标记，不能混用；
体系标签用于初筛，仍须核对实际耦合器、耳廓、原始/补偿状态、佩戴与测量条件。
ISO等研究参考不能直接当成任意入耳耳机的711目标。

另有20条OpenDSP原创相对EQ偏好：平直、V型、温暖、明亮、低音量补偿、
人声/播客、监听延展，以及ACG甜润/清亮/柔顺女声、燃系、OST、电子、器乐、
轻微U型、低频减量、齿音柔化、暗暖、低频轻补、人声前移。
它们代表相对原声的数字EQ形状，应用时替换当前EQ，不冒充声学标准或个人实测校正。

支持分类、搜索、导入自定义声学目标CSV。自定义目标在当前会话中可选；
AI也可传入`target_points`及测量体系，创建自定义声学目标或相对偏好。

## GUI流程

1. 导入真实耳机原始频响CSV（frequency,db），选择其测量体系。
2. 选目标和拟合范围；默认最多20段、上限8kHz，可提高到32段/20kHz。
3. 点卡片生成预览。计算在后台进行，不会自动改变声音。
4. 查看拟合前后形状误差、受增益限制的频点、前级和所需EQ修正。
5. 应用后使用熟悉音乐实听，必要时撤销或重新测量。

没有耳机测量时，声学目标会提示需要数据；仍可使用听感偏好继续人机调音。
目前没有导入SGOR Luna单体实测数据，不能宣布其已匹配Harman等声学目标。

## AI/MCP流程

MCP 0.4的工具：

- `list_targets`：发现曲线、类型、测量体系、适用类别和来源。
- `get_target`：读取指定曲线完整点列。
- `get_tuning_context`：读取GUI已导入的频响、来源、体系、采样率和当前revision。
- `preview_target`：只读拟合，返回完整候选preset、base_revision、误差、预测点列、
  余量提示以及可直接传给`apply_preset`的`apply_arguments`。
- `apply_preset` / `undo_preset`：成组应用和撤销。
- `reset_output`：按模块恢复默认。

示例：已经在GUI导入711原始测量时：

```json
{"target_id":"harman-ie-2019","band_count":24,"max_hz":8000,"max_boost_db":6,"max_cut_db":12,"max_q":3,"smooth":true,"auto_headroom":false}
```

也可在上述请求中明确提供`measured:[[hz,db],...]`和`measurement_rig:"711"`。
数据必须来自用户或可核验来源，不得由AI编造。
自定义目标使用`target_points`替代`target_id`，并注明`target_kind`、`target_rig`和`target_name`。
旧`apply_curve`仍兼容catalog名称/ID，但现在要求expected_revision，推荐先走预览。

本用户要求0dB基准，因此目标预览默认不自动降低前级，保留当前输出机架。
使用返回的`apply_arguments`可避免再次自动降前级；正增益仍可能触发峰值保护。

## 拟合与验证边界

拟合按实际DSP采样率计算Biquad，不再固定48kHz。
声学数据在1kHz对齐，默认1/6倍频程平滑，校正目标限制在−12至+6dB；
限制段数和Q，6kHz以上避免高Q；逐步拟合后再调整已有频段。
缺数据、重复频点、非有限数值、体系不匹配会被拒绝，不外推缺失测量范围。
IIR滤波器有范围外延伸，拟合上限不是理想砖墙边界。

预测误差为指定区间内的EQ形状误差，不包含矩阵、压缩、限幅、DAC和佩戴变化；
频段数多不意味着必然更好。拟合受限或测量质量不足时，应看残余误差，而非只看“已应用”。
预览不会启动音频、播放测试音或切换输出格式；导入新测量/更换测量体系会使旧方案失效。
