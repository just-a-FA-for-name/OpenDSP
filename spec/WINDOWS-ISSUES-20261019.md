| ABI v2 后遥测读取位置过时 | 统一修正读侧、共享映射检查和崩溃恢复检查的偏移。映射数据检查 PASS；本轮未做真实 APO 崩溃恢复试验。 |

## 仍未解决或未验收

1. **DSD 真机失败，不能标成可用。** 修正后 DSD64 / DoP、176400 Hz / 32-bit 独占已成功打开，用户仍听到噪点和卡顿。已恢复 PCM / 384000 / 32，软件增益恢复 0 dB。证据 `rc4-dsd64-live-20261019.json`、`rc4-dsd64-running-20261019.json`。离线调制器每 80 ms 数据约用 8 ms，不能直接归因于 CPU。需继续核对驱动输出位布局、封包后端点音量是否破坏 DoP 标记、DAC 模式锁定；交接时已回读恢复到 -5 dB。不要未经音量迁移/恢复设计就直接把硬件音量拉满。
2. **DSD128 已真机试听但验收失败，卡顿较64更频繁**；PCM→DSD 为调制转换，DSF/DFF 原始 DSD 透传尚未实现。
3. **长时间独立时钟漂移**：同率直通没有 ASRC，虚拟入口与 USB 输出时钟偏差会积累 FIFO。当前短时未溢出不等于整夜稳定；需数小时记录填充量、欠载/溢出和实听，不应静默加入重采样再宣称零转换。
4. **TEARDSP 的 Windows“侦听此设备”需在本次更新后复测**；当前连接为幻音 4X，旧版本记录不能替代新包验收。
5. **实际登录、休眠恢复、USB/蓝牙热插拔和升级/卸载**尚未完成本次完整回归。
6. 全系统接管目前依赖已安装的虚拟入口。默认路由覆盖常规应用；显式绑定其他输出或自己独占声卡的应用不能据此宣称已强制接管。
